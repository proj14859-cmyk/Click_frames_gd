# Click Frames GD

Record a practice run from the pause menu, verify its replay, measure valid
timing windows and watch a showcase with counters and markers.

Experimental v0.7.0 for classic levels at 240 TPS. A one-tick valid window is
a frame perfect; a plus sign marks a lower bound. Full-route analysis can take
hours. Stop saves completed measurements so Analyze / Resume can continue.

Disable CBF and physics-changing mods. Device validation is still required.
